## 三、反复出现的问题类型（已制度化）

1. **默认空回调掩盖漏接线**：窄屏结果页/历史结果页都因此「点了没反应」。
   → 规则：AI 动作回调一律**必填**，由编译期拦截（已落进 `CLAUDE.md`）。
2. **脚本向 Kotlin 字符串写 `\n` 变成真换行**：连续多次编译报错。
   → 规则：多行 Kotlin 字符串改动用编辑工具，不用脚本替换。
3. **增量编译 / KSP 缓存错乱**：`AppDb_Impl` 找不到符号、`lateinit cleanFilenames`。
   → 处理：重试 → `--rerun-tasks` → `clean`。
4. **清理类功能要并入所有引用源**：会话表 + 对练 turns + 以后新增的来源。
   → 规则：删文件前先列全引用集，再按保留期判定。
5. **跨会话异步写必须带归属校验**：生成完成时用户可能已切到另一场。
   → 规则：写入前比对 sessionId/topic，finally 也要判。
