7 天备考课表

IELTS STUDY PLAN · SCHEDULE / PROGRESS / MANUAL SWAP
图名 ielts-study-plan_workflow · 级别 L2 · 2026-11-06 · 配套旁路 ielts-study-plan_workflow.json

主路径

entry
入口
首页「今日任务」右侧「7 天计划 ›」。用户主动进入，不自动弹。
input
读取输入
考试日期、四科目标/最近 Band、到期卡与错题、手动覆盖（Prefs.studyPlanOverrides）、练习记录（status=done）。
calc
排期计算
课表只排到考试日；考前 1 天转 LIGHT；距考 ≥8 天才排模考；>21 天才给休息；每科保底一次，其余按离目标差用最高均数法分配；相邻不排同科。
progress
进度回填
按本地日期 + status=done：练习日看当天科目（换过按换后的判）；模考日听力/阅读任意一套即完成；待评分/跟读/别的科目不算。
display
课表展示
7 天卡片 +「本周计划 N 次 · 已完成 M 次」；完成日金色竖条 +「✓ 已完成」；显示科目/说明/预计分钟。
interact
逐日调整
练习日「换一科」循环四科，可「恢复」/「全部恢复」；去练/去模考/看错题分别跳写作、口语、题库、语料页。
empty
空/失败出口
未设日期 → 均衡排 7 天；考试已过 → 停止倒排并提示改日期；无练习日 → 空态「去设置考试日期」。

边

从到条件 / 载荷

硬规则

  • 课表只排到考试当天；考试日期已过时停止倒排，避免「距考试 -3 天」。
  • 考前一天 LIGHT 只安排看错题；REST/EXAM 不显示无动作的「去练」。
  • 手动覆盖只影响那一天；轮回到原科目时自动清掉覆盖。
  • 完成状态只认 status=done，待评分/没听清不打勾。
