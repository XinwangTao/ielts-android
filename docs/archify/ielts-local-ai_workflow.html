主路径

entry
入口
写作页「AI 提纲」；口语页/话题库「AI 范例」；结果页「生词卡」。均为用户主动点击，不自动触发。
gate
本地模型检查
检查 LocalLlmEngine 是否有可用模型（qwen3-4b-instruct / qwen35-2b）；未就绪直接给设置页引导。本批不接云端：讯飞额度已死，功能定位就是离线可用。
gen
本地生成
LocalLlmEngine.generateText（串行闸门 + 心跳 + 8 分钟上限）；与评分共用同一引擎，评分进行中会排队。
parse
解析与兜底
优先解析约定 JSON；字段缺失按单项丢弃；整体坏了退化为纯文本展示，保证永远有东西可看。
outline
写作提纲卡
立场 + 3 组「论点/解释/例子」+ 5 个可复用短语；只展示，不预填正文；可复制。
sample
口语范例卡
Band 7 范例答案 + 5 个关键词 + 3 段结构提示；接现有 TTS 朗读；可收藏进素材库。
vocab
生词预览与入库
从本次作文/转写 + 逐句改法提取 5-8 条搭配；勾选后写入 cards 表（source=ai_vocab，按 front 去重），进入现有 SRS。
fail
失败出口
超时/空输出/模型未就绪：明确文案 + 重试按钮；写作与口语主流程不被阻断，结果页已有内容照常展示。

边

从到条件 / 载荷

gategen模型就绪
gatefail模型未就绪

范围内

  • 写作 Task 2 提纲（Task 1 复用同一入口，输出改为 overview + 2 段数据要点）
  • 口语 Part 1/2/3 范例答案（从当前题目生成）
  • 评分结果生成生词/搭配卡并进入 SRS

明确不做

  • 不做实时语音评分（端侧 ASR + LLM 时延过高）
  • 不做自动改写用户正文（保留用户自己的产出）
  • 不改云端 provider 与计费策略
  • 不做后台自动生成（必须用户主动触发，避免抢内存）

关键决策

  • 生成一律走 generateText + 专用 system prompt，不新增 JNI / 不换模型
  • 本批只走本地模型，不接云端：讯飞额度已死，功能定位是离线可用
  • 所有输出先展示、再由用户决定是否落库；只有生词卡写 cards 表
  • 文案强调「本地模型生成，仅供参考」，避免与考官评分混淆

待确认

  • 口语范例是否需要一键收藏进素材库（需新增持久化）？
  • 生词卡是否同时支持从「范文/材料」而不只是本次结果提取？
