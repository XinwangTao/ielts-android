备份导入 / 恢复

BACKUP RESTORE · SELECT / VALIDATE / PREVIEW / MERGE
图名 ielts-backup-restore_workflow · 级别 L1（待确认） · 2026-11-06 · 配套旁路 ielts-backup-restore_workflow.json
本图是 L1 流程变更的待确认稿：确认前不写实现。重点确认三件事——冲突策略（新增 vs 覆盖）、设置是否随导入覆盖、写入是单事务还是分批。

主路径

entry
选择备份文件
设置页「导入备份（JSON）」→ 系统文件选择器（SAF）。只接受 .json，大小上限 20 MB。
validate
解析与结构校验
校验 version、sessions/cards 是否为数组、单条必填字段。坏条目计入 skipped；整体不可解析则中止，不改任何数据。
preview
导入预览
展示「练习 N / 卡片 M / AI 套题 K / 设置 X 项」与冲突策略（默认新增、不覆盖已有 id）。
confirm
二次确认
说明影响与回滚：只新增不删除；建议先导出当前数据。可取消。
merge
合并写入
cards 按 front+type 去重、sessions 按 module+topic+startedAt 去重，id 重新分配；AI 套题写 ai_bank.json 按 id 去重；设置仅勾选时覆盖。
summary
结果报告
新增 / 跳过 / 失败计数，失败原因前 3 条；语义（全无或全有 / 部分成功）在确认页写明。
abort
中止 / 报错
解析失败、版本不支持、超限、事务失败：直接给原因，不写任何数据。

连线

从到条件
entryvalidate选中文件
validateabort结构不合法
validatepreview校验通过
previewconfirm用户继续
confirmabort取消
confirmmerge确认导入
mergesummary写入完成
mergeabort事务失败

范围

  • 做：从导出 JSON 恢复 sessions / cards / 范文 / AI 套题；预览与二次确认；可选覆盖设置。
  • 不做：逐条冲突取舍界面、跨设备云同步、录音文件恢复（备份不含音频字节）。

待确认的决策

  • 冲突一律「新增」而非覆盖（id 重新分配）。
  • 设置默认不覆盖，需在确认页显式勾选。
  • 单事务 vs 分批：若分批，确认页必须写明「部分成功」语义。
  • AI 套题的音频不随备份走，导入后按纯文字版使用。
