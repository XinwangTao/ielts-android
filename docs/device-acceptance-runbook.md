## 0. 连接与准备

```bash
# 手机与电脑同一 Wi-Fi；开发者选项 → 无线调试
adb pair <ip>:<配对端口> <6位配对码>     # 仅首次
adb connect <ip>:<调试端口>
adb devices                              # 状态应为 device

# 安装/覆盖安装 debug 包
adb install -r app/build/outputs/apk/debug/app-debug.apk

# 清日志后复现问题（另开窗口持续看）
adb logcat -c
adb logcat -s SPIKE IELTS ScoreService LlmRouter WavRecorder AndroidRuntime

# 截图（失败项留存）
adb exec-out screencap -p > shot_<场景>.png
```

- **清数据**：`adb shell pm clear com.txw.ielts` 会连 `files/models` 一起删，模型需重新投递；
  只想清记录时在 App 设置页操作，不要用 pm clear。
- **跨天场景**：临时关自动时间，把系统时间调到 23:59 操作，再调到次日 08:00 检查；测完恢复自动时间。
